# The SUPER Repo

An open-source AI operating environment for engineering, research, design, automation, and creation.

## Repository status

This repository contains an executable JavaScript runtime, capability registries, a repository analyst, a CLI, and mission/task-graph persistence and recovery. It remains under development: the audited main baseline has failing runtime tests and substantial work on unmerged branches. See the [2026-10-06 reconciliation](docs/audits/2026-10-06-reconciliation.md) for verified scope, test results, and integration priorities, and the [reference integration plan](docs/REFERENCE-INTEGRATION-PLAN.md) for the next capability stages.

## Design goals

- Real executable capabilities, not placeholder catalogs
- Modular agents, skills, tools, commands, and workflows
- Multi-model and multi-harness compatibility
- Persistent memory and project knowledge
- Browser, terminal, filesystem, Git, GitHub, MCP, and domain tool support
- Security, permissions, auditability, and human approval
- Evaluation, benchmarking, observability, and continuous improvement
- Domain packs for software, AI/ML, research, design, finance, science, 3D/CAD, electronics, media, and more

See `ARCHITECTURE.md`, `ROADMAP.md`, and `docs/REPOSITORY-MAP.md` for the current plan.
