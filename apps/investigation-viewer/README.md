# Investigation report viewer

This browser viewer is written in TypeScript and TSX alongside SUPER's JavaScript CLI and runtime. It accepts the JSON generated by `super investigate` and displays findings, source locations, skipped files, and analysis limits. The report is loaded from a local file input and is never uploaded.

From the repository root:

```sh
npm ci
npm run test:viewer
node apps/cli/src/index.js investigate path/to/app --json > investigation.json
cd apps/investigation-viewer
python3 -m http.server 8000
```

Open `http://localhost:8000` and choose `investigation.json`. The app imports compiled `dist/` files produced by the build. The root `tsconfig.json` enables TypeScript beside JavaScript; existing JavaScript is not converted or typechecked during this incremental step.
