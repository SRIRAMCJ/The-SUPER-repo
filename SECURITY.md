# Security Policy

Security is a first-class part of SUPER Repo.

## Security principles

- Least privilege
- Explicit authorization
- Default deny for sensitive capabilities
- No secret material in source control
- Validate inputs at trust boundaries
- Treat external content as untrusted
- Record security-sensitive actions in auditable form
- Require appropriate human approval for high-impact actions
- Maintain security regression tests

## Protected surfaces

- Filesystem
- Shell/terminal
- Network
- Browser
- Credentials
- MCP servers and tools
- Plugins
- Agent execution
- Production/deployment actions
- External communications

## Reporting

Do not disclose an exploitable vulnerability publicly before maintainers have had an opportunity to assess and remediate it.
